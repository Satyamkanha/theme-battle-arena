# Theme Battle Arena 🎮

Theme Battle Arena is a theme-based Tic Tac Toe Android application developed using Java and XML in Android Studio.

Instead of the traditional X and O symbols, players can choose different themes where custom images are used as game pieces.

## Features

### 🏏 Cricket Arena

* Bat vs Ball gameplay
* Image-based game board

### ⚽ Football Clash

* Football vs Goal Post gameplay

### 🍔 Food Fight

* Burger vs Pizza gameplay

### 🎮 Gamer Duel

* Controller vs VR Headset gameplay

### General Features

* Theme Selection Screen
* Interactive Game Board
* Winner Detection
* Draw Detection
* Restart Game Functionality
* Mobile-Friendly UI
